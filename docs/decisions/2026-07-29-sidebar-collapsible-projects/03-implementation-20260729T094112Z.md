## Notes on the `init()` test

`init()` is hostile to jsdom: it awaits `document.fonts.load` (no `FontFaceSet`
in jsdom) and registers five `on*` IPC listeners, and the shared `installApi()`
replaces `globalThis.window` wholesale with `{ api }` — which would break
`window.addEventListener` at the end of `init()`. Handled by capturing the real
jsdom window at module load (before any `beforeEach` clobbers it), restoring it
for that test, `defineProperty`-ing a stub `document.fonts`, and wrapping the
api object in a `Proxy` whose `get` falls back to a no-op mock. That keeps the
stub honest about the five calls that matter without hand-listing every
listener.
